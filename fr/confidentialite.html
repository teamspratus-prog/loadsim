Confidentialité

Ce que ce site conserve

Le simulateur est un ensemble de fichiers statiques qui s'exécutent dans votre navigateur. Il n'y a ni compte, ni base de données, ni endroit où vos données de chargement pourraient aller. Cette page nomme tout ce qu'il écrit et les deux requêtes qu'il fait sortir de votre machine.

La version courte

Tout tourne sur votre machine

  • Aucun compte, aucune adresse courriel, aucune connexion
  • Aucun témoin. Le site n'en dépose aucun et n'en lit aucun
  • Les pages vues sont comptées sans témoin, sans identifiant gardé dans votre navigateur et sans publicité
  • Vos dimensions, vos quantités et vos scénarios enregistrés ne sont jamais transmis — le code du simulateur ne contient aucun appel réseau
Stockage du navigateur

Quatre clés, sur votre appareil

Le simulateur écrit ces clés dans le localStorage de votre navigateur pour que votre configuration survive à un rechargement. Elles restent sur l'appareil qui les a écrites et ne sont lisibles que par ce site.

clStateV1

La configuration en cours : l'unité de transport et ses dimensions intérieures, les dimensions de palette et de boîte, les couches, les niveaux, les pièces par boîte, le poids par pièce, les panneaux ouverts, le niveau de zoom et l'angle de vue.

clScenariosV1

Les scénarios que vous avez enregistrés par nom, chacun contenant une copie complète de la configuration ci-dessus et la date d'enregistrement.

clShowEmptyV1

Si la surimpression de l'espace vide est activée. Un seul caractère.

clThemeV1

Votre choix clair ou sombre, partagé par toutes les pages du site.

Si le stockage n'est pas disponible

Chaque lecture et chaque écriture est protégée pour qu'une fenêtre privée, des données de site bloquées ou un disque plein ne puissent pas casser l'outil. Il fonctionne normalement et oublie simplement votre configuration d'une visite à l'autre.

Pour tout retirer

Réinitialiser dans le panneau Cargo efface la configuration en cours mais conserve délibérément vos scénarios enregistrés. Pour tout supprimer, effacez les données de site de ce domaine dans les réglages de votre navigateur — il n'existe aucune copie côté serveur dont il faudrait demander la suppression.

Codes de partage

Un code de partage est votre configuration et vos scénarios encodés en texte, dans votre propre navigateur. Il n'est téléversé nulle part. Partout où vous le collez, la destination le voit — traitez donc un code comme les dimensions et les quantités qu'il contient.

Hors de votre machine

Deux requêtes externes

Google Fonts. Les pages chargent deux polices — la feuille de style depuis fonts.googleapis.com et les fichiers de police depuis fonts.gstatic.com. Votre navigateur fait ces requêtes directement, ce qui veut dire que votre adresse IP, votre agent utilisateur et la page d'origine parviennent à Google, sous leur politique de confidentialité plutôt que celle-ci. Rien de votre chargement n'y est inclus.

Vercel Web Analytics. Un petit script compte les pages vues, pour voir quelles pages servent vraiment. Il enregistre la page ouverte, la page d'où vous arrivez, et des informations grossières d'appareil et de pays. Il ne dépose aucun témoin et ne garde aucun identifiant dans votre navigateur, et rien de votre chargement — dimensions, quantités ou scénarios enregistrés — n'y est inclus. Vercel le traite sous ses propres conditions.

Ce sont les deux seules requêtes que le site fait à qui que ce soit. Le simulateur lui-même n'en fait aucune : son code ne contient aucun appel réseau, et c'est pour cela que vos données de chargement n'ont nulle part où aller. Si vous préfériez que les polices ne soient pas non plus téléchargées, elles peuvent être hébergées avec les autres fichiers, et la pile retombe sur une vraie police système sans elles.

Hébergement

Les fichiers sont servis par Vercel, qui comme tout serveur web enregistre des journaux de requêtes ordinaires — adresse IP, horodatage, page demandée et agent utilisateur. C'est le fonctionnement normal d'un serveur, et c'est distinct de ce que fait le simulateur lui-même.

Désactiver le comptage

La seule technologie ici qui observe quoi que ce soit est le compteur de pages vues décrit plus haut. Il ne dépose aucun témoin et ne garde aucun identifiant, il n'y a donc aucun profil à désactiver — mais si vous préférez qu'il ne s'exécute pas du tout, n'importe quel bloqueur de contenu l'arrête, et le reste du site fonctionne exactement pareil sans lui. Rien d'autre sur le site ne vous identifie, ne vous localise ni ne vous suit.
